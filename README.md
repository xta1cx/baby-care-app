# ベビーケアアプリ

赤ちゃんのミルク・おむつ・睡眠を記録するWebアプリです。

## 概要

赤ちゃんの日々の記録を簡単に入力・管理できるアプリです。

以下の記録に対応しています。

- 🍼 ミルク
- 💩 おむつ
- 🌙 睡眠

記録した内容は履歴一覧で確認できます。

## 主な機能

- ミルクの記録
- おむつの記録
- 睡眠時間の記録
- 記録履歴の一覧表示
- 記録の削除
- データがない場合のメッセージ表示
